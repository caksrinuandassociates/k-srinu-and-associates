# K Srinu and Associates - Professional Audit & Taxation Website

This is a complete static multi-page website built for **K Srinu and Associates**, designed for:

- Chartered Accountants
- Auditors
- Tax Consultants
- Financial Advisors

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Custom CSS

## Features

- Sticky responsive navbar with mobile hamburger menu
- Professional hero and business sections
- Service cards with hover interactions
- About and Why Choose Us sections
- Contact details, WhatsApp CTA, and maps embed placeholder
- Reusable custom utility styles
- Smooth scrolling and subtle reveal animations
- SEO-friendly meta tags and semantic markup
- GitHub Pages ready

## Local Run (VS Code Live Server)

1. Open folder `k-srinu-and-associates` in VS Code.
2. Right-click `index.html` and choose **Open with Live Server**.

## Deploy to GitHub Pages

1. Push this folder contents to a GitHub repository.
2. In GitHub repo settings, open **Pages**.
3. Set source to `Deploy from a branch`.
4. Select your main branch and root folder.
5. Save and open the generated site URL.

## Customization Notes

- Replace contact placeholders in `index.html` and `contact.html`.
- Add actual social media links in footer sections.
- Add logos/photos into `assets/images/` and update image references.
