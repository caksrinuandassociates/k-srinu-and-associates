Backup & Restore

1. Frontend Backup

Current frontend is managed in GitHub repository. Browser admin cannot safely produce a complete source-of-truth backup for code history.

Open GitHub Repository Download Repository ZIP 
git clone https://github.com/caksrinuandassociates/k-srinu-and-associates.git
git pull origin main
git archive --format=zip --output=frontend-backup.zip main

This backs up HTML, CSS, JS, images, partials, sitemap, robots, and admin panel code.

2. Backend Data Backup

One-click export of CMS/backend tables to a JSON backup file.

  • site_settings
  • compliance_calendar
  • team_members
  • career_openings
  • notifications
  • contact_submissions
  • career_applications

3. Storage Backup Notice

Team images are stored in Supabase Storage bucket: team-images.

JSON backup stores image_url references only, not physical image files.

For complete storage backup, download the bucket manually from Supabase dashboard.

4. Backend Restore

Upload a backup JSON file, validate structure, then confirm restore using keyword.

No backup file selected.

Restore uses upsert by id. It does not delete/truncate existing data.

5. Warnings

  • Always download frontend GitHub backup before major edits.
  • Always export backend data before running restore.
  • Restore does not restore Supabase Auth users.
  • Restore does not restore Supabase Storage files.
